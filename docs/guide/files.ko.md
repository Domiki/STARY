# 파일과 세션

## 파일 추가

파일이나 폴더를 역할 행에 끌어 놓거나, 옆의 **+** 를 눌러 파일을 고르세요. STARY가 파일 정보(형식, 크기, 노출,
ISO)를 읽고 확인을 요청합니다. 파일이 많으면 상태 바에 진행 상황이 나옵니다. 추가할 수 없는 파일은 이유와 함께
표시됩니다. 예를 들어 중복, 세션의 다른 파일과 다른 크기, 지원하지 않는 형식입니다.

**Delete** 키나 우클릭 → **목록에서 … 제거**로 목록에서 뺄 수 있습니다. STARY의 목록에서만 빼는 것이고
디스크의 파일은 그대로입니다.

## 세션

세션은 함께 쓰는 프레임을 묶습니다. Light 프레임과 그에 맞는 Dark, Flat, Dark Flat, Bias 프레임입니다. 밤마다,
카메라 구성마다, 노출마다 하나의 세션을 쓰세요.

- 파일 패널 머리글의 **+** 로 세션을 추가하고, 세션 이름을 더블클릭하면 이름을 바꿉니다. **×** 는 세션을
  지웁니다.
- 보정은 **세션별로** 적용됩니다. 각 세션이 자기 Dark, Flat, Bias를 씁니다.
- Stacking 모드에서는 Light가 있는 모든 세션이 함께 스택됩니다. [딥스카이 스태킹](deep-sky.md#several-sessions)을
  참고하세요.

## 역할

| 역할 | 프레임 |
|---|---|
| **Light** | 하늘을 찍은 사진 |
| **Dark** | 렌즈 캡을 닫고, Light와 같은 노출과 ISO로 찍은 것 |
| **Flat** | 균일하게 밝힌 면을 찍은 것. 비네팅과 먼지를 보정 |
| **Dark Flat** | Flat과 같은 노출로 찍은 Dark |
| **Bias** | 렌즈 캡을 닫고 가장 짧은 노출로 찍은 것 |

## Master 프레임

이미 master dark, flat, bias가 있다면 해당 역할의 유일한 파일로 추가하고, 우클릭해서 **Master로 지정**을
선택하세요. **MASTER** 표시가 붙고 STARY가 프레임을 합치지 않고 그대로 씁니다. **Master 해제**로 되돌립니다.

## 대표 이미지

각 세션에는 별 표시가 붙은 대표 Light 이미지가 있습니다. 다른 프레임들이 정렬되는 기준 프레임이고 하늘 마스크를
만드는 사진입니다. 기본은 첫 번째 Light이고, 다른 Light를 우클릭해서 **대표 이미지로 지정**하면 바뀝니다.

## 경고와 표시

파일 옆의 경고 아이콘은 맞지 않는 부분이 있을 수 있다는 뜻이고, 마우스를 올리면 내용이 나옵니다.

- **노출**이나 **ISO/Gain**이 대표 Light와 다릅니다(한 역할 안에서는 첫 파일과 비교).
- **파일 형식**이 세션의 나머지와 다릅니다.
- **JPEG/PNG**로 하는 보정은 정확도가 낮습니다.

스택이 끝나면 사용되지 않은 Light 프레임에 **제외** 표시가 붙고, 마우스를 올리면 이유(예: *다른 프레임보다
흐립니다*)가 나옵니다.
