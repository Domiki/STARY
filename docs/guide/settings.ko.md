# 설정

## 설정 창

창 오른쪽 위의 설정 버튼으로 엽니다.

- **연산 장치** — **CPU** 또는 **GPU**. 버튼 아래에 CPU 스레드 수와 GPU 이름과 백엔드(Metal, DirectX 12,
  Vulkan)가 나옵니다. GPU가 감지되면 자동으로 선택됩니다. GPU는 스태킹을 빠르게 하고, CPU는 항상 동작합니다.
  이미지가 GPU 메모리에 들어가지 않거나 GPU에서 문제가 생기면 CPU를 선택하세요.
- **메모리 예산** — STARY가 쓸 수 있는 여유 메모리의 비율(10~80%, 기본 50%). 예산이 클수록 더 많은 프레임을
  동시에 처리합니다.

## 그 밖의 선택

- **파일 읽기**(보정 섹션): *정확* 또는 *빠름*. [보정](calibration.md)을 참고하세요.
- **디모자이킹 품질**(모드 섹션): 센서 원본 데이터를 컬러 이미지로 바꿉니다. *빠름*이 대부분의 작업에 충분합니다.
  *높음*은 더 느린 방식(X-Trans 센서에서는 3-pass 알고리즘)을 쓰고 몇 배에서 수십 배 오래 걸릴 수 있습니다.
  시험에서는 스택의 잡음 수준이 달라지지 않았습니다.
- **언어**: 창 오른쪽 위의 설정 버튼. *시스템 언어*는 시스템을 따르고, 영어와 한국어를 쓸 수 있습니다.

## 업데이트

STARY는 시작할 때 GitHub의 릴리스 목록을 확인합니다. 더 새로운 버전이 나왔다면 릴리스 노트와 다운로드 페이지로 가는 버튼이 있는 창이 나타나고, **닫기**를 누르면 지금 쓰는 버전을 그대로 씁니다. STARY가 인터넷에 요청하는 것은 이것뿐이고, 사용자나 파일에 관한 정보는 전혀 보내지 않습니다. 설정(오른쪽 위 버튼)의 **시작할 때 새 버전 확인**으로 끌 수 있고, *도움말 → STARY 정보*의 **업데이트 확인**으로 언제든 직접 확인할 수 있습니다.

!!! note
    연산 장치, 메모리 예산, 파일 읽기 선택은 STARY를 다시 켜면 기본값으로 돌아갑니다.
