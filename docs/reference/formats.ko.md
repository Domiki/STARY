# 지원하는 파일

| 형식 | 비고 |
|---|---|
| **카메라 RAW** | LibRaw로 읽습니다. 센서 원본 값을 쓰므로 보정이 정확합니다. Bayer와 X-Trans(후지필름) 센서를 처리합니다. |
| **FITS** | 원본(Bayer 또는 X-Trans 패턴), 컬러, 흑백. 천체 카메라의 FITS와 Siril이 만든 파일을 읽습니다. |
| **TIFF**, **PNG**, **JPEG** | 완성된 이미지로 읽습니다. 보정은 동작하지만 카메라나 편집기가 값을 가공했기 때문에 정확도가 낮습니다. |

## 확인한 것

- 후지필름 X-Pro3(X-Trans)와 소니(Bayer)의 카메라 RAW
- Siril이 만든 FITS 파일과 master 프레임(X-Trans 패턴)
- 별 궤적용 JPEG

천체 카메라의 파일(Bayer FITS)과 PNG/TIFF 입력은 합성 데이터로만 시험했습니다. 예시 파일과 함께 알려 주시면
큰 도움이 됩니다.

## 출력

결과는 자동으로 32비트 float TIFF로 저장됩니다. 다른 형식은 [결과 저장](../guide/saving.md)을 참고하세요.

## 세션 안의 규칙

한 세션의 모든 프레임은 크기와 화소 배열이 같아야 합니다. 맞지 않는 파일은 추가할 때 이유와 함께 거부됩니다.
