Trust

Code signing policy

How the Windows installers of STARY are signed, who is responsible, and what the program sends over the network.

Signing

Free code signing for the Windows installers is provided by SignPath.io, with a certificate from the SignPath Foundation. Only installers built from the public source code in the repository by its GitHub Actions workflow are signed, and every release is approved by hand before it is signed.

Until the signing is set up, the installers are not signed and Windows may show a warning. See Download.

Privacy

STARY works on your own computer. Your photographs are never uploaded, and the program collects no personal data, usage statistics or crash reports.

The only network request the program makes is a check for a newer version when it starts: it asks the GitHub releases list of this project (api.github.com) and sends only the usual parts of such a request, such as your IP address and the name and version of the program. You can turn it off in Settings by switching off Check for updates. Nothing is downloaded or installed by it; it only tells you that a newer version exists.

Installing and removing

The installer does not change your system settings beyond installing the program. To remove STARY on Windows, use Settings → Apps → Installed apps and choose Uninstall for STARY.
