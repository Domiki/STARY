System requirements

Memory16 GB or more is recommended for 24–26 megapixel RAW files. The memory budget in the settings limits how much STARY uses.
GraphicsOptional. A GPU with Metal, DirectX 12 or Vulkan speeds up stacking. Without one, the CPU is used.
DiskResults are 32-bit float TIFF files; a 26-megapixel result is about 300 MB.
InputCamera RAW, FITS, JPEG, PNG and TIFF.

The first time you open it

The pre-release builds are not signed by a paid developer account, so your system shows a warning once.

macOS

Open the .dmg and drag STARY to Applications. If macOS refuses to open it, right-click the app and choose Open, or allow it under System Settings → Privacy & Security → Open Anyway. If it says the app is damaged, remove the quarantine flag:

xattr -cr /Applications/STARY.app

Windows

Run the installer. If Windows SmartScreen appears, choose More info → Run anyway. If Microsoft Defender blocks the file as a virus, it is a false alarm that unsigned new programs often cause: open Windows Security → Virus & threat protection → Protection history, choose the blocked STARY item and Allow on device, then download it again. The installer needs the WebView2 runtime, which is already part of Windows 11. To remove STARY, use Settings → Apps → Installed apps. See the code signing policy.

Build from source

STARY is built with Tauri (Rust and React). You need Rust (the exact version is pinned in rust-toolchain.toml) and Node.js.

git clone https://github.com/Domiki/STARY.git
cd STARY
npm install
npm --prefix ui install
npx tauri build

On Windows you also need the Visual Studio Build Tools (C++ workload) and LLVM, which is used to compile LibRaw; see .cargo/config.toml. The installers appear under target/release/bundle.
